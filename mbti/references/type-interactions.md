## 一、术语约定

| 中文 | 英文 | 说明 |
|------|------|------|
| 互动框架 | Interaction Framework | 描述两型之间动态关系的结构化视角 |
| 互补型 | Complementary | 功能轴互补：一方的优势是另一方的辅助或第三 |
| 对立型 / 阴影型 | Opposite / Shadow | 功能栈完全相反（1 位 = 对方 4 位），共享功能但顺序倒置 |

## 二、三类互动框架

### 1. 同类型互动（Same-Type Interaction）

**结构**：两型相同（如 INTJ ↔ INTJ）。

| 维度 | 表现 |
|------|------|
| **理解速度** | 极快——共享语言、节奏、价值 |
| **盲区叠加** | 高——双方劣势功能（如 INTJ 共同的 Se）同时薄弱 |
| **共同风险** | 共谋式的盲点放大（如两个 INTP 可能长期搁置执行）|
| **适配建议** | 刻意引入第三方或外部工具补足共同劣势 |

### 2. 互补型互动（Complementary Interaction）

**结构**：功能轴互补——一方的优势功能恰好是另一方的辅助或第三功能。

经典互补组合示例：

| 一方 | 另一方 | 互补机制 |
|------|--------|----------|
| INTJ（Ni-Te-Fi-Se）| ENFP（Ne-Fi-Te-Si）| 共享 Te-Fi 判断轴，感知轴互补 |
| ISTJ（Si-Te-Fi-Ne）| ESFP（Se-Fi-Te-Ni）| 共享 Te-Fi 判断轴，感知轴互补 |
| INFJ（Ni-Fe-Ti-Se）| ENTP（Ne-Ti-Fe-Si）| 共享 Ti-Fe 判断轴，感知轴互补 |
| ISTP（Ti-Se-Ni-Fe）| ISFJ（Si-Fe-Ti-Ne）| 共享 Ti-Fe 判断轴，感知轴互补 |

| 维度 | 表现 |
|------|------|
| **相互成长** | 高——能彼此补足盲区 |
| **沟通成本** | 中等——需磨合不同的节奏与价值排序 |
| **冲突来源** | 优势功能在对方眼里"用力过猛"（如 Te 主导者让 Fi 主导者感到被否定）|
| **适配建议** | 建立显式分工：让各自的优势功能负责对应领域 |

### 3. 相反型 / 阴影型互动（Opposite / Shadow Interaction）

**结构**：功能栈完全相反，1 位 = 对方 4 位、2 位 = 对方 3 位。

| 对立对 | 共享功能 |
|--------|----------|
| INTJ ↔ ESFP | Ni/Se + Te/Fi |
| INTP ↔ ESFJ | Ti/Fe + Ne/Si |
| INFJ ↔ ESTP | Ni/Se + Ti/Fe |
| INFP ↔ ESTJ | Fi/Te + Ne/Si |
| ISTJ ↔ ENFP | Si/Ne + Te/Fi |
| ISFJ ↔ ENTP | Si/Ne + Ti/Fe |
| ISTP ↔ ENFJ | Ti/Fe + Se/Ni |
| ISFP ↔ ENTJ | Fi/Te + Se/Ni |

| 维度 | 表现 |
|------|------|
| **视角扩展** | 极大——能体验完全相反的世界观 |
| **冲突强度** | 高——容易陷入"对方的强项正是我的痛处"的互相刺激 |
| **共同风险** | 把差异误读为"对方性格有缺陷" |
| **适配建议** | 把对方的强项识别为"系统级互补资源"，而非个人攻击；建立显式沟通协议 |

> 三类互动没有绝对优劣。互补型并非"最佳"，相反型也非"最差"——任何配对都需要看双方的成熟度、意识水平与情境支持。

## 三、Keirsey 四气质分组与互动偏好

> Keirsey 根据 S/N 与 J/P 的组合，将 16 型分为四气质。每组共享沟通偏好、价值排序与协作节奏。

### NF 理想主义者（Idealists）— INFP · INFJ · ENFP · ENFJ

| 维度 | 特征 |
|------|------|
| **核心追求** | 意义（Meaning）、本真（Authenticity）、深度关系 |
| **沟通偏好** | 真诚、隐喻、共情式倾听；不喜欢生硬的批评 |
| **互动雷区** | 被工具化、价值被否定、关系流于表面 |
| **最佳激励** | 看见其独特性、与其共同塑造愿景 |

### NT 理性者（Rationals）— INTJ · INTP · ENTJ · ENTP

| 维度 | 特征 |
|------|------|
| **核心追求** | 能力（Competence）、知识、自主权 |
| **沟通偏好** | 智力对等、逻辑辩驳、信息密度高 |
| **互动雷区** | 被情绪化绑架、被微观管理、被无依据的权威压制 |
| **最佳激励** | 给难题、给自主权、认可其专业能力 |

### SJ 守护者（Guardians）— ISTJ · ISFJ · ESTJ · ESFJ

| 维度 | 特征 |
|------|------|
| **核心追求** | 秩序（Order）、责任（Responsibility）、传统 |
| **沟通偏好** | 规则明确、流程透明、长期承诺 |
| **互动雷区** | 频繁变更、轻视规矩、不可靠 |
| **最佳激励** | 给稳定预期、认可其贡献与坚守 |

### SP 艺术创造者（Artisans）— ISTP · ISFP · ESTP · ESFP

| 维度 | 特征 |
|------|------|
| **核心追求** | 行动（Action）、自由（Freedom）、当下体验 |
| **沟通偏好** | 务实、简洁、共同体验；不喜欢冗长说理 |
| **互动雷区** | 被冗长束缚、被剥夺动手空间、被迫长期规划 |
| **最佳激励** | 给具体挑战、给弹性、认可其现场解决问题的能力 |

### 跨气质互动的常见张力

| 配对 | 典型张力 | 缓解方向 |
|------|----------|----------|
| NF ↔ SJ | 理想 vs 现实、愿景 vs 规矩 | 把 NF 的愿景翻译成 SJ 可执行的步骤 |
| NT ↔ SP | 抽象规划 vs 当下行动 | 让 SP 负责"落地"，NT 负责"系统" |
| NF ↔ NT | 情感意义 vs 逻辑效率 | 区分讨论"做不做"（NF 主导）与"怎么做"（NT 主导）|
| SJ ↔ SP | 长期秩序 vs 当下灵活 | 划定不可让步的底线 + 留出 SP 的灵活区 |

## 四、类型识别访谈问题模板

> 访谈识型的核心原则：**问行为，不问认同**；**问过去，少问假设**；**避免引导性提问**（不要让选项直接露出字母）。
> 每个维度提供 3 个开放式问题，按需选用。

### 维度 1：能量来源（E / I）

1. 一整天会议或聚会结束之后，你更想找人继续聊，还是独自待一会儿？为什么？
2. 在一个完全陌生的新团队里，你通常会先认识所有人，还是先观察一段时间？
3. 当你需要"想清楚一件事"时，你是边说边想（找人讨论），还是先在脑中走完再开口？

### 维度 2：信息收集（S / N）

1. 学一个新东西时，你更想先看具体步骤说明，还是先理解它背后的原理和可能？
2. 描述一件你最近经历的事，你会更多用什么词：具体的细节、数字、颜色，还是比喻、图景、可能性？
3. 当朋友给你讲一个新点子时，你本能反应是问"怎么落地"，还是问"还能怎么扩展"？

### 维度 3：决策方式（T / F）

1. 朋友做了一个你认为不太好的决定，你会先指出问题，还是先共情他/她的感受？
2. 做一个重要选择时，你更常问自己"什么是对的 / 什么最有效"，还是"这对每个人意味着什么"？
3. 在冲突中，你更想先厘清事实与责任，还是先修复关系？

### 维度 4：生活方式（J / P）

1. 出去旅行，你更喜欢把每天行程安排好，还是只定大致方向、留出大量弹性？
2. 截止日期对你来说是"提前完成"的安心，还是"最后一搏"的动力？
3. 面对一个待决定的事项，你倾向于"尽快了结"，还是"再多看看选项"？

### 访谈流程建议

1. **先听完，不下判断**——记录关键词而非字母。
2. **追问情境**——"能举个具体例子吗？" 比直接问偏好更可靠。
3. **区分基线与情境**——"这是你平时的状态，还是最近压力下的状态？"
4. **交叉验证**——同一维度从工作、家庭、休闲三个场景各取一次证据。
5. **回到功能栈**——结合 [`cognitive-functions.md`](cognitive-functions.md) 推导功能栈，再用 4 字母验证；两者不一致时，**以功能栈证据为准**。

## 五、类型误判的常见原因

> 单次类型判断的复测稳定性研究差异较大，多数综述认为在线自评工具的短期一致性偏低（部分研究低于 50%）。
> 因此分析时需识别下列系统性误判源。

| 误判源 | 机制 | 典型表现 |
|--------|------|----------|
| **社会面具（Persona）** | 职业角色要求掩盖真实偏好 | 内向者因长期做销售被训练出外向表达 → 自评 E |
| **压力下的行为偏差** | 长期压力激活劣势或阴影功能 | INTJ 在 Se grip 下变得纵欲享乐 → 被误判为 SP |
| **性别角色期待** | 男性被鼓励 T，女性被鼓励 F | 男性 F 主导者误自评为 T，反之亦然 |
| **文化背景** | 东亚文化鼓励 J 与 S 的外在表达 | N/P 倾向者被环境训练为"务实、计划" → 自评偏向 SJ |
| **仅凭职业推断** | 用刻板印象套类型 | "程序员都是 INTx" "护士都是 IxFJ" |
| **自我理想化** | 选择"想成为"的选项而非真实选项 | 把"我希望我擅长社交"勾选为"我擅长社交" |
| **单一时间窗口观察** | 成熟者四个功能都已有一定发展 | 中年人在不同情境下看起来像不同类型 |
| **在线测试信度问题** | 自评量表对情境与情绪敏感 | 心情好与差时测试结果差异显著 |
| **家人/伴侣的描述偏差** | 重要他人只在特定情境观察 | 母亲描述的孩子可能仅反映家庭角色 |
| **二分法思维** | 把偏好当作"是 / 不是" | "我有时也喜欢独处，所以我肯定是 I" |

### 防范建议

- 把"自评字母"视为**假设**而非结论。
- 至少在 2 周以上的不同情境中收集行为证据。
- 始终用功能栈证据（参见 [`cognitive-functions.md`](cognitive-functions.md)）做交叉验证。
- 在用户描述不一致时，描述具体观察、不轻易断言类型。

## 六、禁用表达清单

> 以下表达方式**禁止**在任何 MBTI 解读中使用。完整法律与伦理边界见 [`../../references/disclaimer.md`](../../references/disclaimer.md)。

1. ❌ 不得将 MBTI 作为评判他人**智力、能力、道德、品行**的依据（如"NT 型才适合做战略"）。
2. ❌ 不得作为**招聘筛选、晋升、调岗、辞退**的唯一或主要依据。
3. ❌ 不得作为**婚恋匹配、伴侣选择、分手决定**的唯一依据。
4. ❌ 不得**替代精神科诊断、心理评估或医疗建议**（人格障碍、抑郁、焦虑等不在 MBTI 范畴）。
5. ❌ 不得给他人**贴固定标签**（如"你这种人就是没同理心"）。
6. ❌ 不得在**未征得对方明确同意**的情况下"鉴定"或公开他人的类型。
7. ❌ 不得使用**宿命论表述**（如"你注定不擅长 X"、"你们类型天生合不来"）。
8. ❌ 不得把类型差异**泛化为性别、年龄、地域、种族偏见**。
9. ❌ 不得用功能分析**贬低、嘲讽、攻击**他人或群体。
10. ❌ 不得用 MBTI **预测他人的具体行为、疾病、寿命、犯罪倾向**等。

## 七、高风险主题强制现实建议

> 当用户问题涉及以下主题时，**MBTI 解读之外必须附现实专业路径建议**；
> 表格风格与边界规则参考根目录 [`../../references/disclaimer.md`](../../references/disclaimer.md) 第三节。

| 主题 | 必须建议的现实路径 |
|------|------------------|
| 心理危机 / 自伤念头 / 严重情绪障碍 | 联系心理危机热线或精神科，告知可信赖的亲友 |
| 抑郁、焦虑、人格障碍相关疑虑 | 咨询精神科医生或临床心理咨询师，不以 MBTI 解释症状 |
| 婚恋中的家暴、人身安全 | 拨打 110 或当地报警电话，联系反家暴机构 |
| 亲密关系中的强制控制 / 精神虐待 | 咨询心理咨询师与法律援助机构 |
| 职场霸凌 / 歧视 / 不当解雇 | 咨询劳动法律师、工会或 HR 合规渠道 |
| 招聘与就业歧视争议 | 依据《劳动法》《就业促进法》等寻求法律咨询 |
| 子女教育与抚养争议 | 咨询教育专家、心理咨询师或家事律师 |
| 重大职业转型 / 跳槽 / 创业 | 结合职业规划师、行业 mentor 与现实财务测算 |
| 团队冲突升级 / 职场申诉 | 走正式申诉流程，必要时寻求法律意见 |

### 强制条款

遇到用户表达**自伤、自杀、伤害他人**意图时：

1. **立即停止 MBTI 解读**；
2. **优先提供危机干预资源**（中国大陆可拨打心理援助热线 `12356`；有即时危险时拨打当地紧急服务，中国大陆为 `120` / `110`）；
3. 鼓励用户联系可信赖的亲友或精神科急诊；
4. **不得**用"类型差异""功能失衡"等 MBTI 语言解释危机信号。

> MBTI 是偏好与动机的描述模型，**不是临床诊断工具**，不替代精神科诊断、心理评估或医疗建议。
> 涉及重大决策（婚恋、就业、医疗、法律、财务）时，请结合现实信息理性判断，并咨询对应领域的合格专业人士。
