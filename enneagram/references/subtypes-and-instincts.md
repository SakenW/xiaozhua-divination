## 一、三种本能（Instincts）

九型理论在核心类型之上叠加三种**动物性本能**（Instinctual Variants），每种本能的强弱组合产生 27 种副型（Subtypes）。

### 1.1 自保本能（Self-Preservation, Sp）

- **关注焦点**：身体与物质安全感——生存、温饱、健康、居所、财务、舒适度
- **典型表现**：谨慎、计划、囤积资源、在意健康饮食作息、对未知风险敏感
- **关键词**：安全、稳定、储备、舒适、健康、实用
- **失衡态**：过度焦虑、囤积癖、回避一切风险、忽视关系

### 1.2 社交本能（Social, So）

- **关注焦点**：群体归属与社会角色——人际关系网、地位、声誉、群体规范
- **典型表现**：在意他人评价、热衷社群活动、关注世界动态、对等级与角色敏感
- **关键词**：归属、角色、关系网、地位、贡献、群体
- **失衡态**：过度讨好、社恐、迷失自我于群体、社交焦虑

### 1.3 性本能（Sexual / One-to-One, Sx）

- **关注焦点**：一对一深度联结与吸引力——亲密关系、性、强烈的吸引与被吸引
- **典型表现**：渴求深度交流、容易被强烈的人或事吸引、追求刺激与肾上腺素、不喜欢表面社交
- **关键词**：亲密、吸引、深度、激情、刺激、专注
- **失衡态**：沉迷、占有欲强、频繁关系危机、对无聊极度不耐烦

### 1.4 本能叠加规则

每人都有三种本能，按**强弱排序**形成"本能堆叠"（Instinctual Stacking）：

- **Sp/So/Sx**：最稳重，重物质与社会身份
- **Sx/Sp/So**：热烈且聚焦亲密关系
- **So/Sx/Sp**：外向、社交灵活但有深度
- 共 6 种排列，每种影响外在气质显著

## 二、27 副型组合表

每种核心类型 × 三种本能 = 一种独特副型，呈现该类型与该本能的**混合表达**。
Naranjo 体系为每个副型取了独特的命名（如 6 So 称"责任/义务"，与 6 Sp"温暖/亲和"、6 Sx"力量/美"差异显著）。

### 2.1 自保副型（Sp）—— 9 行

| 类型 | Naranjo 命名 | 一句话特征 |
|------|-------------|-----------|
| 1 Sp | 焦虑 / 担忧（Anxiety） | 用整齐与控制环境缓解生存焦虑，比其他 1 更内向、谨慎 |
| 2 Sp | 特权 / 像我一样（Privilege） | 通过照顾他人的物质需求换取被爱的资格 |
| 3 Sp | 安全 / 工作狂（Security） | 用工作成就与物质积累构建安全感，比其他 3 低调 |
| 4 Sp | 隐忍 / 坚韧（Tenacity） | 用忍耐与坚持维护独特性，比其他 4 更务实 |
| 5 Sp | 隐士 / 巢穴（Castle / Retreat） | 极度保护私密空间与能量，把家视为安全堡垒 |
| 6 Sp | 温暖 / 亲和（Warmth） | 用友善与结盟换取安全感，最随和的 6 |
| 7 Sp | 族群 / 守护（Family / Defenders） | 把享乐与一群亲密伙伴绑定，比其他 7 更稳定 |
| 8 Sp | 满意 / 生存（Satisfaction / Survival） | 用物质掌控与舒适度证明力量，务实 |
| 9 Sp | 食欲 / 习惯（Appetite） | 通过满足口腹之欲与日常习惯维持内心平静 |

### 2.2 社交副型（So）—— 9 行

| 类型 | Naranjo 命名 | 一句话特征 |
|------|-------------|-----------|
| 1 So | 不适应 / 非适应（Non-adaptation） | 用理想化原则对抗社会现状，比其他 1 更改革性 |
| 2 So | 野心 / 公使（Ambition） | 通过社会贡献与地位换取被需要感 |
| 3 So | 声望 / 形象（Prestige） | 全力追逐社会声望与群体认可，最外显的 3 |
| 4 So | 羞耻 / 公众（Shame / Social) | 用独特性博取社会目光，敏感于被评判 |
| 5 So | 图腾 / 思想家（Totem / Ideas） | 用思想影响群体，追求智力上的社会地位 |
| 6 So | 责任 / 义务（Duty） | 严守责任与规范换取群体保护，最守规矩的 6 |
| 7 So | 牺牲 / 社会工作者（Sacrifice） | 用群聚享乐服务他人，比其他 7 更利他 |
| 8 So | 友谊 / 同盟（Comradeship） | 通过保护追随者构建力量同盟，最具领袖气质 |
| 9 So | 参与 / 联结（Participation） | 通过融入群体维护和谐，最外向的 9 |

### 2.3 性本能副型（Sx）—— 9 行

| 类型 | Naranjo 命名 | 一句话特征 |
|------|-------------|-----------|
| 1 Sx | 热情 / 嫉妒（Zeal / Jealousy） | 用改革激情改造他人，比其他 1 更外向热烈 |
| 2 Sx | 诱惑 / 攻击性（Seduction / Aggression） | 通过强烈吸引力与性魅力赢得被爱 |
| 3 Sx | 男性 / 女性（Masculinity / Femininity） | 通过极致性别魅力与性吸引获得认可 |
| 4 Sx | 竞争 / 仇恨（Competition / Hate） | 用激烈竞争证明独特性，嫉妒心最强 |
| 5 Sx | 信心 / 拒绝（Confidence / Rejection） | 极度专注一位理想对象，渴求深度共鸣 |
| 6 Sx | 力量 / 美（Strength / Beauty） | 通过力量或美貌赢得保护，最张扬的 6 |
| 7 Sx | 迷人 / 建议者（Suggester / Fascination） | 追求刺激体验与新颖关系，最易沉迷 |
| 8 Sx | 占有 / 背叛（Possession / Betrayal） | 通过绝对占有与掌控证明力量，最强烈的 8 |

## 三、副型访谈识别问卷

通过开放式问题让用户**自述行为**（而非认同标签），避免引导性偏差。

### 3.1 自保（Sp）识别

1. "你新到一个陌生环境，最先担心的是什么？"（答物质/安全/居所 → Sp）
2. "你怎么安排每月的开销？"（答预算/储蓄/计划 → Sp）
3. "生病或不适时你第一反应？"（答就医/休养/恢复 → Sp）
4. "周末理想状态？"（答在家/舒适/独处 → Sp）

### 3.2 社交（So）识别

1. "在群体中你更关注什么？"（答角色/氛围/关系网 → So）
2. "你如何看待自己的社会地位？"（答在意/比较/贡献 → So）
3. "陌生人多的场合你的状态？"（答寻找归属/融入/观察等级 → So）
4. "你重视朋友们的什么？"（答共同价值观/群体身份/社会影响 → So）

### 3.3 性本能（Sx）识别

1. "你更容易被什么样的关系吸引？"（答深度/强烈/一对一 → Sx）
2. "你对'无聊'的耐受度？"（答极度不耐/追求刺激 → Sx）
3. "遇到让你心动的人或事，你的反应？"（答极度专注/沉醉/不眠 → Sx）
4. "你如何看待表面社交？"（答不喜欢/觉得肤浅 → Sx）

## 四、健康层级（Levels of Development）

Riso-Hudson 体系将每型的健康程度分为 **9 阶**，分三档：

### 4.1 健康档（1-3 阶）

| 阶 | 总体特征 |
|----|---------|
| 1 | 解放态：超越类型限制，整合对立品质 |
| 2 | 心理功能态：自如运用本型优势 |
| 3 | 社会价值态：本型天赋发挥，贡献他人 |

### 4.2 平均档（4-6 阶）

| 阶 | 总体特征 |
|----|---------|
| 4 | 平衡态：本型特质明显但可控 |
| 5 | 人际控制态：开始用本型策略操控环境 |
| 6 | 过度补偿态：本型特质僵化，防御明显 |

### 4.3 不健康档（7-9 順）

| 阶 | 总体特征 |
|----|---------|
| 7 | 侵犯态：本型缺陷严重外显 |
| 8 | 妄想态：脱离现实，沉溺本型幻想 |
| 9 | 病理态：自我毁灭倾向，需专业干预 |

**应用**：解读时先评估用户当下大致在哪个层级，4-6 阶最常见，描述时用平均档特征；遇 8-9 阶迹象（自毁/脱离现实），**立即停止类型解读**，按 [disclaimer.md](../../references/disclaimer.md) 第三节流程转向专业心理资源。

## 五、与 MBTI、大五人格的对照

不同体系管不同维度，可互补但不可互换。

| 维度 | 九型人格 | MBTI | 大五人格（Big Five） |
|------|---------|------|--------------------|
| 核心问题 | **动机**（为什么这样做）| **认知方式**（怎么处理信息）| **可测量特质**（行为表现）|
| 理论基础 | 动机 / 恐惧 / 欲望 | 认知功能 / 偏好 | 因子分析 / 实证数据 |
| 类型数 | 9 型 × 27 副型 | 16 型 | 5 维度（连续值）|
| 稳定性 | 核心类型一生基本不变，副型与层级动态 | 成年期稳定，压力下变阴影 | 随年龄缓慢变化 |
| 科学性 | 心理学界存疑（缺乏实证）| 心理学界存疑（缺乏实证）| 学术主流认可（有信效度）|

**实践建议**：
- 用九型看**深层动机与成长方向**
- 用 MBTI 看**沟通与信息处理偏好**
- 用大五看**可量化的特质强度**
- 三者描述同一人时，看到的是不同侧面，不应强求一致

## 六、禁用表达清单

| # | 禁用 | 理由 |
|---|------|------|
| 1 | "你是 X 号，所以一定 XX" | 反对类型刻板印象，强调健康层级与个体差异 |
| 2 | "你这种人不适合做 XX 工作" | 不做职业/婚恋/教育决策的唯一依据 |
| 3 | "你不健康 / 你有病" | 不做精神科诊断，类型不是病理标签 |
| 4 | "你需要 X 号的人才能完整" | 类型不可作为关系匹配的绝对判断 |
| 5 | "你这是 X 号的缺陷" | 不强调负面，改用"成长方向" |
| 6 | 用九型做招聘筛选、孩子分班 | 违反伦理，类型不是能力评估工具 |
| 7 | 给他人贴标签却不让其本人参与 | 尊重当事人自我认同 |
| 8 | 用九型解释家暴、伤害等行为 | 不为伤害行为提供类型借口 |

## 七、高风险主题强制现实建议

当用户问题涉及以下主题时，解读之外**必须**附现实专业路径建议：

| 主题 | 必须建议的现实路径 |
|------|------------------|
| 疾病 / 身体症状 / 用药 | 就医，咨询执业医师，不擅自停药或更改治疗方案 |
| 心理危机 / 自伤念头 / 严重情绪障碍 | 联系心理危机热线或精神科，告知可信赖的亲友 |
| 法律纠纷 / 诉讼 / 合同 | 咨询执业律师，以法律条文与司法程序为准 |
| 大额投资 / 理财 / 买房 / 创业 | 咨询注册会计师、持牌理财顾问 |
| 婚恋中的家暴 / 人身安全 | 拨打 110 或当地报警电话，联系反家暴机构 |

完整免责声明见 [`../../references/disclaimer.md`](../../references/disclaimer.md)。

遇到表达自伤、自杀、伤害他人意图时，**立即停止九型解读**，优先提供危机干预资源。
