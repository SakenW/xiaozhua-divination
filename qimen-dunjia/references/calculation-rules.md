## 一、九宫格（洛书九宫）布局

洛书九宫以方位固定，排列如下：

```
巽四宫（东南）| 离九宫（南）  | 坤二宫（西南）
震三宫（东）  | 中五宫（中央） | 兑七宫（西）
艮八宫（东北）| 坎一宫（北）  | 乾六宫（西北）
```

洛书数口诀：戴九履一，左三右七，二四为肩，六八为足，五居中央。

## 二、四层盘面说明

奇门遁甲由四层盘面叠加组成：

| 盘面 | 内容 | 元素 |
|------|------|------|
| 地盘（第一层） | 三奇六仪，固定基础 | 乙丙丁（三奇）+ 戊己庚辛壬癸（六仪） |
| 天盘（第二层） | 九星，随值符移动 | 天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英 |
| 人盘（第三层） | 八门，随值使移动 | 休门、生门、伤门、杜门、景门、死门、惊门、开门 |
| 神盘（第四层） | 八神，随值符宫位旋转 | 值符、螣蛇、太阴、六合、白虎、玄武、九地、九天 |

中五宫无星门，天盘九星和人盘八门各只有八个，分布于八宫。

## 三、三奇六仪及排列顺序

**六仪**（阳干）：戊、己、庚、辛、壬、癸

**三奇**（阴干，实为乙丙丁三奇异）：乙、丙、丁

**完整序列（九个符号）**：戊 己 庚 辛 壬 癸 丁 丙 乙

六甲旬与旬首对应：
| 旬 | 旬首 | 六仪值 |
|----|------|-------|
| 甲子旬 | 甲子 | 戊（甲子与戊同宫） |
| 甲戌旬 | 甲戌 | 己（甲戌与己同宫） |
| 甲申旬 | 甲申 | 庚（甲申与庚同宫） |
| 甲午旬 | 甲午 | 辛（甲午与辛同宫） |
| 甲辰旬 | 甲辰 | 壬（甲辰与壬同宫） |
| 甲寅旬 | 甲寅 | 癸（甲寅与癸同宫） |

## 四、六甲隐遁规则

六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅）不显于盘面，各自隐遁于旬首六仪之下：

- 甲子隐于戊
- 甲戌隐于己
- 甲申隐于庚
- 甲午隐于辛
- 甲辰隐于壬
- 甲寅隐于癸

因此地盘显示的是九个符号（戊己庚辛壬癸丁丙乙），甲字不出现在盘面。

## 八、阴阳遁规则

| 节气 | 遁别 | 说明 |
|------|------|------|
| 冬至 → 夏至前 | 阳遁 | 冬至一阳生，从一局起，依次 1→2→3...→9→1 循环 |
| 夏至 → 冬至前 | 阴遁 | 夏至一阴生，从九局起，依次 9→8→7...→1→9 循环 |

**阳遁排盘方向**：地盘天干顺时针排列（坎一宫→坤二宫→震三宫→巽四宫...）

**阴遁排盘方向**：地盘天干逆时针排列（坎一宫→乾六宫→兑七宫→艮八宫...）

## 九、用局表简化说明

**局数确定原则**：

1. 先确定当前节气区间（24节气，每气约15天）
2. 再确定当前日柱所在六甲旬的三元（上元/中元/下元）——本仓库采用"符头法"：四仲符头（甲子/甲午旬）→上元，四孟符头（甲申/甲寅旬）→中元，四季符头（甲戌/甲辰旬）→下元。
3. 对照下方"节气×三元→局数表"查得局数（即《烟波钓叟歌》口径，与 `scripts/qimen_cli.py:JU_TABLE` 完全一致）。

## 十、排盘七步流程概要

```
Step 1：确定阴阳遁
  → 查当前日期所处节气，判断阳遁/阴遁

Step 2：定局数
  → 查节气×旬首对照表，确定局数（1-9）

Step 3：排地盘
  → 以局数对应天干为起点，阳顺阴逆依次填入九宫
  → 例：阳遁7局，以庚为7局首，庚落坎一宫，辛落坤二宫...

Step 4：排天盘（九星）
  → 找旬首天干所在地盘宫位 → 该宫位安置天辅（或对应值符星）
  → 其余八星按原宫间距关系平移

Step 5：排人盘（八门）
  → 查当前时辰对应的值使门
  → 以值使门临地盘旬首宫位，其余七门按原宫间距关系平移

Step 6：排神盘（八神）
  → 值符星所在宫位 = 值符神所在宫位
  → 其余七神按阳顺阴逆依次填入其余七宫

Step 7：标注中宫寄宫
  → 天禽星：阳遁寄坤二宫，阴遁寄艮八宫
  → 中五宫不设门神，在表格中注明"寄X宫"
```
