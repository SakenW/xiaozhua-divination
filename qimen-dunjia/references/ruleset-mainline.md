# `mainline-cn-v1` 默认规则

这个 skill 的正式排盘只使用这一套默认规则，不在正式计算里混用别的说法。

## 适用范围

- 面向中国大陆常见时家转盘奇门使用习惯
- 默认时区：`Asia/Shanghai`
- 海外用户必须先补城市或时区

## 固定规则

### 1. 时间规则

- 用户说"现在"，就按当前绝对时间起局。
- 没给时区且语境是中国大陆，默认北京时间。
- 海外用户没给时区时，先追问，不要直接排盘。

### 2. 节令规则

- 以节令切换阴遁 / 阳遁。
- 冬至到芒种：阳遁
- 夏至到大雪：阴遁
- 节气边界前后 24 小时内，输出中要明确写出"边界提醒"。

### 3. 三元规则

- 按日干支在六十甲子序列中的位置分组。
- 每 5 日为一元。
- 顺序固定循环为：上元 -> 中元 -> 下元。

这是当前版本采用的工程化固定规则，用来确保同一输入得到同一结果。

### 4. 定局规则

- 阴遁 / 阳遁与三元确定后，从固定定局表直接取局数（见 `references/calculation-rules.md` 第九节，72 条局数与《烟波钓叟歌》口径一致）。
- **三元采用"符头定元法"**：以日柱所在六甲旬的旬首（甲X）地支属性判定整个旬的元归属：
  - 四仲符头（甲子、甲午）→ 上元
  - 四孟符头（甲申、甲寅）→ 中元
  - 四季符头（甲戌、甲辰）→ 下元
  - 即一个六甲旬（10 天）内所有日期归同一元。这是时家奇门置闰法的标准口径。
- **与其他排盘软件的差异提示**：部分软件采用"五日一元严格对齐节气"或"拆补法"，在节气交界附近（约 1-3 天）可能给出不同的元/局。本仓库统一采用符头定元法，不切换变体。
- 不在正式排盘时临时切换拆补法或其他变体。

### 4.1 子时换日

- 时辰在 23:00-00:59 整段视为次日子时，日柱推进一天（"子时归次日"口径）。
- 本脚本未显式 +1 天，而是依赖 lunar_python 的 `getDayInGanZhiExact()` 默认行为，效果与紫微、六爻脚本一致。

### 5. 中宫规则

- 中宫相关判断一律寄坤处理。
- 如果旬首所遁之仪或时干落在中宫，正式输出里要提示"本盘按寄坤处理"。

### 6. 展示规则

- 不展示完整推理链。
- 只展示关键计算结果和必要依据。
- 用户主要看到的是：阴阳遁、局数、旬首、旬空、值符、值使、关键用神。

## 不支持的情况

以下情况不进入正式排盘：

- 用户明确要求切换到别的规则，但不接受当前默认规则
- 缺少时间或地点信息
- 想让模型跳过脚本直接手算
