## 二、按领域补充的边界提示

### 中华术数（紫微斗数 / 八字 / 奇门遁甲 / 六爻）

- 命理仅供参考，**不构成婚姻、事业、投资、医疗、生育、诉讼等决策依据**。
- 不同流派在早晚子时、置闰、起卦方式上存在口径差异，解读结果非唯一正确答案。
- 严禁使用恐吓式表达（"必死""无救""注定破财"等），遇凶象只描述倾向并给出现实化解方向。

### 占星（西方占星 / 塔罗）

- 占星与塔罗属于象征与原型系统，用于自我觉察与反思，**不替代专业心理咨询或医疗诊断**。
- 不以占星结果预判他人的具体行为、疾病、寿命或灾难。

### 人格模型（MBTI / 九型人格）

- MBTI 与九型人格是**偏好与动机的描述模型，不是临床诊断工具**，**不替代精神科诊断、心理评估或医疗建议**。
- 不得用于给他人贴标签、做招聘筛选、婚恋匹配的唯一依据，或用于贬低、评判他人。
- 人格类型存在流动性与测量误差，单次结果不应固化对自我或他人的判断。

## 三、高风险主题强制现实建议

当用户问题涉及以下主题时，解读之外**必须**附现实专业路径建议：

| 主题 | 必须建议的现实路径 |
|------|------------------|
| 疾病 / 身体症状 / 用药 | 就医，咨询执业医师，不擅自停药或更改治疗方案 |
| 心理危机 / 自伤念头 / 严重情绪障碍 | 联系心理危机热线或精神科，告知可信赖的亲友 |
| 法律纠纷 / 诉讼 / 合同 | 咨询执业律师，以法律条文与司法程序为准 |
| 大额投资 / 理财 / 买房 / 创业 | 咨询注册会计师、持牌理财顾问，结合财务报表与尽调 |
| 婚恋中的家暴 / 人身安全 | 拨打 110 或当地报警电话，联系反家暴机构 |
| 子女教育 / 抚养争议 | 咨询教育专家、心理咨询师或家事律师 |

遇到表达自伤、自杀、伤害他人意图时，**立即停止术数解读**，优先引导联系当地紧急服务与可信赖的亲友，并将对话转向寻求现实帮助。中国大陆存在即时危险时优先拨打 `110` 或 `120`；心理危机可拨打 `12356`。
