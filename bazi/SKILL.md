## 核心规则

### 解释边界

- 命盘展示的是倾向、结构、课题与机会，不是绝对命定。
- 不用恐吓式、宿命式表述，不说"注定如此""无法改变"。
- 健康、法律、财务等问题只能做命盘角度的结构提醒，不能替代现实专业意见。
- 以专业命理研究者口吻输出，但不要故弄玄虚。
- 结论要有依据，尽量体现推演过程。不要只说好听的话，也不要刻意吓人，要客观平衡。

### 读盘证据纪律（v2.1 新增）

**双模式定义**：
- **盲推模式**（无履历锚点）：只交付「结构底盘＋候选框架＋索锚点问题」，禁止事件级/形态级编年式断言。流年干支只能提供概率气候（性格骨架/压力周期/资源形态），不能直接命令断言。
- **对表模式**（已有 2-5 个真实履历锚点）：先铺开履历时间轴，再逐年对表，标注 ✓/◐/✗；未中锚点的推断一律降级或作废。

**铁律四条**：
1. **锚点先行**：无事实地基不做事件级断言；首轮读盘以索锚点问题收尾（如「哪年开始工作的」「哪年离开的」）。
2. **岁运优先**：定位大事件年时，先扫「流年×大运」关系（天克地冲/天合地合/伏吟/拱合制化），再扫「流年×原局」。十年内大事件的主要引擎是岁运关系，不是流年与原局的普通生克。
3. **跨运核对**：引用「流年×大运」关系前，必须先核对该流年确实处于该步大运起止年份内，防跨运错挂。
4. **流年核对**：书写任何流年干支前，以脚本输出或万年历逐年核对（立春换年界），防笔误串年。

**多解分支**：同一干支组合多种含义（如禄神逢冲＝离职/搬迁/感情动/手足伤），必须列 2-4 个候选事件并标注首选与置信度，不留单选断言；候选须包含「组合形态」（如「关系稳定＋人身流动」的双轨态），不许只列单点事件。

**分辨率预期**：离场型事件（离职/分手/迁居）干支显影锐利，可给到年；进场型事件（入职/开学/定情之始）信号温和，只给区间。时辰粒度不足时，交运节点默认 ±1 季度容差。结构层判词（强弱/格局/倾向）可信度高可直说；事件层必须锚点背书后才可断言。

### 逻辑优先级

1. 先确认出生信息与口径（公历/农历、子时换日、是否启用视太阳时修正）。
2. 再调用本地脚本按天干地支规则严格排盘。
3. 再做日主强弱、格局、十神、喜用忌分析。
4. 如果经验口诀与实际排盘推演冲突，**以推演结果为准**。

### 默认口径

- 子时处理：脚本默认使用 `lunar_python sect=1`，即晚子时（23:00-23:59）日柱按次日；`00:00-00:59` 已是新公历日，不再额外推进。
- 如用户明确偏好晚子时不换日，使用 `--sect 2`，即 23:00-23:59 仍取当日柱，并在输出中明确标注。
- 晚子时是否换日是命理界的流派分歧，可能改变日柱及其派生结果；遇到 23:00-23:59 出生者，应先与用户确认口径或两种都算出供参考。

## 工作流程

### 第一步：确认命造信息

必须收集：
1. 出生日期（公历优先，农历需标注是否闰月）
2. 出生时间（精确到时辰，最好到分钟）
3. 性别（影响大运顺逆）
4. 出生地（涉及视太阳时校正时需要可靠经度）
5. **在世状态**：若分析对象已故，需收集去世年份——大运流年只推算到该年为止，不向已故之后推算（避免对在世亲属造成困扰，也避免逻辑错误）。
6. 如果用户已经有可信的排盘软件结果或现成命盘，优先先校盘，再进入正式解读，避免重复换算带来口径偏差。

### 第二步：脚本排盘

从 `xiaozhua-divination` 技能根目录调用统一 wrapper：

```bash
python3 scripts/run_bazi.py \
  --date 1990-10-21 --time 15:30 --gender female \
  --format markdown
```

常用参数：

- `--date-type solar|lunar`：默认公历；农历输入时标注是否闰月。
- `--leap-month`：农历闰月输入时启用。
- `--true-solar-time --longitude <经度>`：用户明确要求视太阳时（俗称真太阳时）且出生地经度可靠时启用；脚本会同时记录经度差项与均时差项。
- `--sect 1|2`：默认 `1`（23:00-23:59 日柱按次日）；`2` 为晚子时不换日。该编号遵循 `lunar_python` 的真实语义。
- `--dayun-limit 1..10`：限制返回的大运条目，超出引擎可用范围会被拒绝。
- `--format json|markdown`：后台推演优先 JSON，展示给用户可用 markdown。

脚本会输出四柱、天干十神、藏干十神、纳音、旬空、命宫/身宫、起运和大运。格局、喜忌及用户自愿参与的历史事件反思性对照仍按下列步骤由解读层完成。

脚本内部排盘口径对应：

#### 2.1 定年柱
- 以立春为界换年，不以正月初一。

#### 2.2 定月柱
- 以节气为界换月（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）。
- 月干按"年上起月法"推算。

#### 2.3 定日柱
- 需要万年历或精确计算。本仓库默认采用 `sect=1`：23:00-23:59 的晚子时日柱按次日；`sect=2` 时晚子时仍按当日。
- 日柱是八字的核心，必须准确。

#### 2.4 定时柱
- 按"日上起时法"推算时干。
- 子时(23-01) 丑时(01-03) 寅时(03-05) 卯时(05-07) 辰时(07-09) 巳时(09-11) 午时(11-13) 未时(13-15) 申时(15-17) 酉时(17-19) 戌时(19-21) 亥时(21-23)

#### 2.5 自检
- 确认年干阴阳是否与顺逆排大运一致
- 确认月支是否对应正确节气
- 确认十神推算无误
- 若脚本不可用，明确说明无法正式排盘，不要手算伪造完整命盘。

### 第三步：分析日主强弱

按以下维度判断：
1. **令**：日主生于何月，是否当令
2. **地**：日主在地支中是否有根（通根、余气）
3. **势**：印比多则强，食伤财官多则弱
4. **综合**：身强/身弱/从格判定

### 第四步：格局与喜用神

1. 判断格局类型（正格、特殊格局）
2. 确定喜用神、忌神
3. 说明判断依据

### 第五步：十神配置分析

重点解读：
1. 性格特征、思维方式、为人处事
2. 事业方向、财运模式
3. 婚姻感情、家庭关系
4. 健康隐患

### 第六步：大运流年推演

#### 排大运规则
- 阳年（甲丙戊庚壬）男、阴年（乙丁己辛癸）女 → 顺排
- 阴年男、阳年女 → 逆排
- 以月柱干支为基准顺/逆推
- 起运年龄：出生日到下一个/上一个节气的天数 ÷ 3 = 年数

#### 推演要求
1. 先说本命盘底色
2. 再说当前大运主题
3. 最后说流年触发点
4. 重点标注“已发生事件”的年份，方便校验
5. 尽量具体到年龄段及年份范围，说明为什么会在那个阶段出现
6. 扫描顺序：先扫「流年×大运」关系（天克地冲/伏吟/拱合制化），再扫「流年×原局」生克——十年内大事件的主要引擎是岁运关系
7. 跨运核对：引用流年与大运的关系前，先核对该流年确实处于本步大运起止年份内，防跨运错挂
8. 无履历锚点时按「读盘证据纪律」盲推模式输出：候选清单式呈现，不编年断事

### 第七步：总结

必须单独总结：
1. 命局核心特点
2. 一生最需要注意的风险点
3. 最值得把握的发展方向
4. 特别关键的年份或阶段

1. 四柱排盘表格
