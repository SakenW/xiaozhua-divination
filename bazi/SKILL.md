# 八字四柱命理

基于子平真诠体系，通过出生年月日时推算四柱八字，分析十神、五行、格局、大运流年。

## 工作流程

### 第一步：确认信息

必须收集：
1. 出生年月日（公历优先）
2. 出生时间（精确到时辰）
3. 性别（影响大运顺逆）

### 第二步：排四柱

按子平法排四柱：
1. **年柱**：以立春为界
2. **月柱**：以节令为界（非农历月初）
3. **日柱**：以子时换日
4. **时柱**：按日干推时干

### 第三步：分析

1. **十神定位**：以日干为我，推六亲十神
2. **五行旺衰**：看日主强弱、得令得地得势
3. **格局判断**：正官格、偏官格、正印格、偏印格、食神格、伤官格、正财格、偏财格等
4. **大运流年**：根据性别和年干阴阳定顺逆
5. **喜忌用神**：根据日主强弱和格局定用神

### 第四步：输出

标准输出格式：
1. 四柱八字
2. 十神关系
3. 五行分析
4. 格局判断
5. 大运排列
6. 流年要点
7. 喜忌建议

## 六亲十神速查

| 十神 | 关系 | 关键词 |
|------|------|--------|
| 正官 | 克我者（异性） | 约束、权威、事业 |
| 七杀 | 克我者（同性） | 压力、冲劲、竞争 |
| 正印 | 生我者（异性） | 学业、贵人、庇护 |
|偏印 | 生我者（同性） | 偏才、孤僻、继母 |
| 比肩 | 同我者（同性） | 兄弟、竞争、独立 |
| 劫财 | 同我者（异性） | 争夺、合作、冲动 |
| 食神 | 我生者（同性） | 才华、口福、子女 |
| 伤官 | 我生者（异性） | 叛逆、才艺、克官 |
| 正财 | 我克者（异性） | 稳定收入、妻子、务实 |
| 偏财 | 我克者（同性） | 横财、父亲、社交 |

## 注意事项

- 八字排盘涉及节令边界，需特别注意立春、惊蛰等节气交接时辰
- 子时换日要明确口径（早子时/晚子时）
- 大运起运年龄需精确计算
- 输出以趋势和结构为主，不做宿命论断
