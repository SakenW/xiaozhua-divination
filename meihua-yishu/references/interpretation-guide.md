# 梅花易数解读指南

本文件只定义小爪命理屋的梅花易数解读边界。固定起卦结果以 `scripts/run_meihua.py` 输出为准。

## 核心结构

- 本卦：当前局面和问题底色。
- 互卦：事情内部的隐含结构、过程和中间状态。
- 变卦：动爻变化后的趋势，不等于绝对结果。
- 动爻：事情变化最敏感的位置，一到三爻偏内在/初始/执行，四到六爻偏外部/后期/结果。
- 体卦：求测者、主体、我方或问题的承载面。
- 用卦：对象、环境、对方或事情的作用面。

## 体用生克

| 关系 | 解读倾向 |
| --- | --- |
| 用生体 | 外部条件支持主体，推进阻力较小 |
| 体生用 | 主体消耗较多，需要投入资源、时间或情绪 |
| 体克用 | 主体能控制局面，但要避免过度用力 |
| 用克体 | 外部压力明显，宜先降风险、补条件 |
| 同气 | 双方同频或问题重复，关键看动爻和现实条件 |

## 输出要求

1. 先展示脚本排出的本卦、互卦、变卦、动爻、体用和生克。
2. 再结合用户问题给出 1 个总判断、2 到 3 条依据、2 到 3 条现实建议。
3. 不用“必然发生”“注定失败”“一定结婚”等确定性表达。
4. 医疗、法律、投资、人身安全等高风险主题只做风险提示，并建议咨询现实专业人士。
